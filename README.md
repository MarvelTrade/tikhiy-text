# Расшифровщик (TikhiyText)

Быстрое нативное macOS-приложение для локальной расшифровки аудио и видео на Apple Silicon (M1/M2/M3) + встроенное снятие стоп-кадров. Без облаков, аккаунтов и подписок.

**Автор:** [Антон Белый](https://github.com/MarvelTrade)

## Возможности

- **Ускоренная локальная расшифровка (`whisper.cpp` + Metal GPU + Flash Attention):**
  - 3 режима скорости: *Быстро (M1)* (`-bs 1`), *Баланс* (`-bs 2`), *Точно* (`-bs 5`).
  - Автоподхват локальных моделей (`ggml-small.bin`, `ggml-large-v3-turbo.bin` и др.).
- **Удобный плеер и работа с текстом (в стиле MacWhisper):**
  - Живой поиск по расшифровке.
  - Клик по фразе перематывает аудио/видео на этот момент, активная фраза подсвечивается.
  - Скорость воспроизведения `1x / 1.25x / 1.5x / 2x`.
  - Копирование всего текста в 1 клик и экспорт в `TXT`, `Markdown`, `SRT`, `VTT`.
- **Встроенные стоп-кадры:**
  - Мгновенный полноразмерный снимок текущего кадра (`AVAssetImageGenerator`).
  - Кнопка стоп-кадра на любом таймкоде фразы.
- **Контроль файлов и кэша:**
  - Массовая выгрузка всех готовых расшифровок в папку.
  - Быстрая очистка временного кэша без удаления моделей.

## Сборка

Требования: macOS 14+, Swift 6+, `ffmpeg`, `whisper-cli` (`brew install ffmpeg whisper-cpp`).

```bash
chmod +x build_app.sh
./build_app.sh
```
